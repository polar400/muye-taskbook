## 专属识别接口

[grocery_recognition.py](../src/grocery_recognition.py) 仅依赖现有 Pillow、vendor NumPy，通过 `GroceryRecognizer` 加载此专属目录。没有改公共 `LocalOCR` 的加载路径，也没有将新素材放入共享 `resources/local/image`。

```python
from PIL import Image
from grocery_recognition import GroceryRecognizer

recognizer = GroceryRecognizer()
with Image.open("resources/local/grocery/sources/user-game.png") as image:
    result = recognizer.recognize_region(image, (412, 300, 88, 88), shop="sun")
assert result["status"] == "recognized"
assert result["item"]["name"] == "封印碎片"
```

`recognize(icon_image, shop=...)` 接收包含原边框／PNG留白的紧贴图标正方形；`recognize_region(image, (x,y,w,h), shop=...)` 使用调用者明确提供的原图像素框。上面的坐标仅适用于该2010×1191附件，不是游戏1920×1015校准坐标，不能直接用来点击。商店键必须明确提供，不从商品图反推商店。

处理流程：RGBA合成到固定暗底，去除6%边缘，归一为48×48，排除右下角数量数字区域；用65%整体RGB结构相似度和35%逐像素色度相似度组合评分，另检查平均绝对像素误差。这样能区分外形接近的风／土手札。当前门槛为相似度≥0.92、误差≤0.12、第一与第二视觉候选领先≥0.035。分数是视觉相似度，不是正确概率。归一化只在内存中进行，原图文件不变。

返回状态为 `recognized`、`unknown`、`ambiguous` 或 `invalid_crop`，只有 `recognized` 包含唯一 `item`。同图多商品或近似图标领先不足必须返回歧义；损坏的素材校验不通过则拒绝加载。返回的商品参考字段不能作为购买授权或实时余额／库存证据。
